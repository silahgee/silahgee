## Profile README Template

A simple and dynamic TypeScript automation script to generate a personalized, rich GitHub Profile README using a single configuration file.

This repository allows you to decouple your profile content from your Markdown structure, keeping your contact details, tech stacks, and tracking badges organized and automated.

## Features

- Manage your personal links and data inside a single `config.json` file.
- Replaces placeholders dynamically from your template file using a lightweight regex engine.
- Automatically converts raw emails outside of `mailto`: tags into an obfuscated format (`user[at]domain[dot]com`) to prevent automated spam harvesters.
- Styled with custom icons from skillicons.dev alongside real-time visitor counts and contribution metrics.
- Validate changes locally without overwriting your master profile document.

## Project Structure

```
├── README.template.md   # The base Markdown file containing data placeholders
├── config.json          # Your personal data inputs
├── build.ts             # TypeScript engine executing variables substitution
├── package.json         # Project metadata, scripts, and dependencies
└── README.md            # The output profile generated by the build engine
```

## Setup & Usage

### 1. Installation
Clone the repository and install the development dependencies:

```bash
npm install
```

### 2. Configure Your Profile

Open [config.json](config.json) and fill in your details:

```json
{
    "firstname": "John",
    "lastname": "Doe",
    "github_username": "johndoe",
    "website": "johndoe.dev",
    "email": "hello@johndoe.dev",
    "twitter_username": "johndoe_dev",
    "logo": "https://githubusercontent.com"
}
```

### 3. Build Your README

To run a test build and confirm your formatting without touching your main document:

```bash
npm run test
```

Outputs to `tests/README.test.md`

To generate your official profile:

```bash
npm run build
```

Outputs directly to `README.md`

## How it works

The underlying build engine uses `tsx` to execute native TypeScript code. The core compiler processes matches matching a `{{variable_name}}` pattern:

```ts
const readme = template.replace(
  /\{\{(\w+)\}\}/g,
  (match, key: string, offset: number, source: string) => {
    const value = variables[key as keyof typeof variables];

    // Handles contextual spam protection for email strings
    if (
      key === "email" &&
      typeof value === "string" &&
      !source.slice(Math.max(0, offset - 7), offset).endsWith("mailto:")
    ) {
      return value.replace("@", "[at]").replace(".", "[dot]");
    }

    return value ?? match;
  },
);
```
